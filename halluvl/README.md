# HalluVL-DPO

Preference data for reducing prompt-induced hallucinations in LVLMs, from the NeurIPS 2026 paper [*When Prompts Override Vision: Prompt-Induced Hallucinations in LVLMs*](https://arxiv.org/abs/2604.21911).

- [`dpo/`](dpo/README.md): the released preference datasets for LLaVA-1.5-7B and Qwen2-VL-7B, and the pipeline that builds them.

See the [repository README](../README.md) for a summary of the paper.
